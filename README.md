## Featured project

### [Multi-Asset Correlation Pipeline →](https://github.com/hannanrazalli/assets-correlation-pipeline)

A daily batch pipeline that ingests equity, Bitcoin, gold ETF and FX data to compare asset returns across 30 shared observations.

- **Pipeline:** Python ingestion → S3 → Glue Data Catalog → dbt on Athena, orchestrated with Airflow.
- **Modeling:** Incremental Apache Iceberg fact table with MERGE, plus returns and correlation models.
- **Engineering:** 32 configured dbt tests; GitHub Actions for linting, DAG import checks and dbt parsing. Architecture, setup and limitations documented in the repo.
